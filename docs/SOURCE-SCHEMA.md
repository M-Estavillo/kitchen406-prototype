## 

| Entity | Final Attributes / Constraints |
| ----- | ----- |
| **Account** | `account_id` PK; `email` UNIQUE; `password_hash`; `first_name`; `last_name`; `role` {customer, staff, admin}; `status` {pending_verification, active, inactive, suspended}; `email_verified_at` nullable; `password_changed_at` nullable; `created_at`; `updated_at` |
| **AdminProfile** | `admin_id` PK; `account_id` FK, UNIQUE → Account |
| **StaffProfile** | `staff_id` PK; `account_id` FK, UNIQUE → Account; `is_temp_pass_changed` default false; `created_by_admin_id` FK → AdminProfile; `created_at`; `updated_at` |
| **CustomerProfile** | `customer_id` PK; `account_id` FK, UNIQUE → Account; `mobile_number`; `created_at`; `updated_at` |
| **AccountVerification** | `account_verification_id` PK; `account_id` FK → Account; `purpose` {email_verification, password_reset, email_change, account_setup}; `otp_code_hash`; `target_email` nullable; `expires_at`; `verified_at` nullable; `attempt_count` default 0; `created_at` |
| **Address** | `address_id` PK; `customer_id` FK → CustomerProfile; `label`; `add_line_1`; `add_line_2` nullable; `city`; `postal_code`; `landmark` nullable; `latitude`; `longitude`; `is_default` default false; `status` {active, archived}; `created_at`; `updated_at` |
| **Category** | `category_id` PK; `category_name` UNIQUE; `status` {active, inactive}; `created_at`; `updated_at` |
| **Product** | `product_id` PK; `category_id` FK → Category; `name`; `description`; `img_url`; `subscription_eligible`; `status` {active, inactive}; `created_at`; `updated_at` |
| **ProductVariant** | `variant_id` PK; `product_id` FK → Product; `size`; `final_price`; `suggested_price`; `utility_overhead` nullable; `status` {available, unavailable}; `created_at`; `updated_at` |
| **PricingConfig** | `pricing_config_id` PK; `default_utility_overhead`; `markup_percentage`; `updated_by_admin_id` FK → AdminProfile; `created_at`; `updated_at` |
| **Inventory** | `inventory_id` PK; `name`; `unit`; `stock_on_hand`; `reorder_threshold`; `cost_per_unit`; `status` {available, unavailable, low_stock}; `created_at`; `updated_at`. **Rule:** `status` is system-maintained whenever available stock or threshold changes. |
| **ProductBOM** | `product_bom_id` PK; `variant_id` FK → ProductVariant; `inventory_id` FK → Inventory; `quantity_required`; UNIQUE (`variant_id`, `inventory_id`) |
| **Cart** | `cart_id` PK; `customer_id` FK, UNIQUE → CustomerProfile; `subtotal`; `created_at`; `updated_at`. `subtotal` is system-maintained from CartItems. |
| **CartItem** | `cart_item_id` PK; `cart_id` FK → Cart; `variant_id` FK → ProductVariant; `quantity`; `added_at`; `updated_at`; UNIQUE (`cart_id`, `variant_id`) |
| **Order** | `order_id` PK; `customer_id` FK → CustomerProfile; `cart_id` FK nullable → Cart; `address_id` FK nullable → Address; `address_snapshot` nullable; `ref_number` UNIQUE; `type` {standard_purchase, subscription_purchase, subscription_fulfillment, custom_cake_purchase}; `total`; `amount_payable`; `placed_at`; `fulfillment_date` nullable; `fulfillment_method` {pickup, delivery} nullable; `status` {pending_payment, confirmed, preparing, ready, completed, cancelled, payment_resolution_required}; `created_at`; `updated_at` |
| **OrderStatusHistory** | `history_id` PK; `order_id` FK → Order; `status`; `changed_by_account_id` FK nullable → Account; `changed_at` |
| **OrderItem** | `order_item_id` PK; `order_id` FK → Order; `variant_id` FK nullable → ProductVariant; `quotation_id` FK nullable, UNIQUE → CustomCakeQuotation; `quantity`; `unit_price_snapshot`; CHECK exactly one of `variant_id` or `quotation_id` is populated |
| **CheckoutHold** | `hold_id` PK; `order_id` FK → Order; `status` {active, confirmed, released, expired}; `created_at`; `expires_at`; `confirmed_at` nullable; `released_at` nullable. Only one active hold per Order. |
| **Payment** | `payment_id` PK; `order_id` FK → Order; `hold_id` FK, UNIQUE → CheckoutHold; `paymongo_id` UNIQUE; `amount`; `qr_img_url`; `status` {pending, paid, failed, expired, cancelled}; `failure_code` nullable; `failure_message` nullable; `created_at`; `expires_at`; `paid_at` nullable. **No refund handling exists in the system.** |
| **Delivery** | `delivery_id` PK; `order_id` FK → Order; `lalamove_id` UNIQUE nullable; `longitude`; `latitude`; `fee`; `status` {pending, booked, in_transit, delivered, failed, cancelled}; `delivered_at` nullable; `created_at`; `updated_at`. Only one active delivery booking per Order. |
| **CapacityConfig** | `capacity_config_id` PK; `order_type` {standard, subscription, custom_cake} UNIQUE; `max_varieties_per_day` nullable; `max_cakes_per_week` nullable; `max_cakes_per_day` nullable; `max_units` nullable; `cutoff_time`; `lead_time_value`; `lead_time_unit` {hours, days}; `created_by_admin_id` FK → AdminProfile; `created_at`; `updated_at` |
| **CapacityAllocation** | `allocation_id` PK; `capacity_config_id` FK → CapacityConfig; `product_id` FK nullable → Product; `source_order_id` FK → Order; `fulfillment_order_id` FK nullable → Order; `hold_id` FK nullable → CheckoutHold; `cycle_number` nullable; `fulfillment_date`; `quantity`; `status` {held, confirmed, fulfilled, released, expired}; `expires_at` nullable; `created_at`; `released_at` nullable |
| **BlockedDate** | `blocked_date_id` PK; `date` UNIQUE; `reason` nullable; `created_by_admin_id` FK → AdminProfile; `created_at` |
| **SubscriptionSchedule** | `schedule_id` PK; `product_id` FK nullable → Product; `preparation_day`; `fulfillment_day`; `status` {active, inactive}; `created_by_admin_id` FK → AdminProfile; `created_at`; `updated_at` |
| **Subscription** | `subscription_id` PK; `customer_id` FK → CustomerProfile; `variant_id` FK → ProductVariant; `purchase_order_id` FK, UNIQUE → Order; `address_id` FK → Address; `schedule_id` FK → SubscriptionSchedule; `quantity_per_delivery`; `product_total`; `delivery_fee_total`; `total_price`; `start_date`; `status` {active, completed, cancelled}; `created_at`; `updated_at`. Subscription length is fixed at exactly four deliveries rather than stored as `week_count`. |
| **SubscriptionDelivery** | `subscription_delivery_id` PK; `subscription_id` FK → Subscription; `fulfillment_order_id` FK, UNIQUE → Order; `cycle_number` {1,2,3,4}; `original_scheduled_date`; `scheduled_date`; `status` {scheduled, preparing, ready, fulfilled, cancelled}; `fulfilled_at` nullable; `created_at`; `updated_at`; UNIQUE (`subscription_id`, `cycle_number`). Exactly four records per successful Subscription. |
| **SubscriptionDeferment** | `deferment_id` PK; `subscription_id` FK, UNIQUE → Subscription; `subscription_delivery_id` FK, UNIQUE → SubscriptionDelivery; `original_allocation_id` FK → CapacityAllocation; `replacement_allocation_id` FK, UNIQUE → CapacityAllocation; `original_scheduled_date`; `new_scheduled_date`; `deferment_option` {next_week, next_day}; `created_at`. Maximum one successful deferment per Subscription. |
| **OrderMaterialRequirement** | `requirement_id` PK; `order_id` FK → Order; `inventory_id` FK → Inventory; `quantity_required`; `fulfillment_date`; `reserve_at`; `created_at`; UNIQUE (`order_id`, `inventory_id`). Represents the aggregated ingredient requirement for that specific fulfillment Order. |
| **InventoryReservation** | `reservation_id` PK; `requirement_id` FK → OrderMaterialRequirement; `hold_id` FK nullable → CheckoutHold; `quantity`; `status` {held, confirmed, consumed, released, expired}; `expires_at` nullable; `created_at`; `consumed_at` nullable; `released_at` nullable. Only one active held/confirmed reservation per requirement. |
| **InventoryMovement** | `movement_id` PK; `inventory_id` FK → Inventory; `order_id` FK nullable → Order; `reservation_id` FK nullable → InventoryReservation; `performed_by_account_id` FK nullable → Account; `movement_type` {consumption, consumption_reversal, restock, adjustment}; `quantity_change`; `unit_cost_snapshot` nullable; `reason` {spoilage, damage, miscount, theft, correction, other} nullable; `notes` nullable; `operation_key` UNIQUE; `occurred_at`. Every physical stock change and corresponding `stock_on_hand` update occurs atomically. |
| **CustomCakeRequest** | `custom_request_id` PK; `customer_id` FK → CustomerProfile; `address_id` FK nullable → Address; `shape_option_id` FK → CakeOption; `flavor_option_id` FK → CakeOption; `size_option_id` FK → CakeOption; `color_option_id` FK → CakeOption; `icing_option_id` FK → CakeOption; `accepted_quotation_id` FK nullable, UNIQUE → CustomCakeQuotation; `ref_number` UNIQUE; `design_description`; `img_url` nullable; `estimated_price`; `requested_date`; `requested_delivery_window` {morning, afternoon, evening}; `fulfillment_method` {pickup, delivery} nullable; `status` {pending_review, negotiating, quoted, accepted, rejected, expired}; `created_at`; `updated_at` |
| **CakeOption** | `option_id` PK; `created_by_admin_id` FK → AdminProfile; `option_type` {shape, flavor, size, color, icing}; `scale_factor` nullable; `option_name`; `price`; `status` {available, unavailable}; `created_at`; `updated_at` |
| **CakeOptionIngredient** | `option_ingredient_id` PK; `option_id` FK → CakeOption; `inventory_id` FK → Inventory; `quantity_required`; UNIQUE (`option_id`, `inventory_id`) |
| **CakeAddon** | `addon_id` PK; `created_by_admin_id` FK → AdminProfile; `name`; `price`; `status` {available, unavailable}; `created_at`; `updated_at` |
| **CakeAddonIngredient** | `addon_ingredient_id` PK; `addon_id` FK → CakeAddon; `inventory_id` FK → Inventory; `quantity_required`; UNIQUE (`addon_id`, `inventory_id`) |
| **CakeRequestAddon** | `cake_request_addon_id` PK; `custom_request_id` FK → CustomCakeRequest; `addon_id` FK → CakeAddon; `quantity`; UNIQUE (`custom_request_id`, `addon_id`) |
| **CustomCakeQuotation** | `quotation_id` PK; `custom_request_id` FK → CustomCakeRequest; `version_number`; `created_by_admin_id` FK → AdminProfile; `fulfillment_date`; `delivery_window` {morning, afternoon, evening}; `fulfillment_method` {pickup, delivery}; `address_snapshot` nullable; `options_total`; `addons_total`; `complexity_charge`; `delivery_fee`; `total`; `status` {draft, issued, superseded, accepted, rejected, expired}; `issued_at` nullable; `expires_at` nullable; `accepted_at` nullable; `created_at`; UNIQUE (`custom_request_id`, `version_number`) |
| **PostDraft** | `draft_id` PK; `product_id` FK nullable → Product; `occasion_id` FK nullable → SeasonalOccasion; `reviewed_by_admin_id` FK nullable → AdminProfile; `category` {new_product_launch, product_highlight, subscription_slots_reminder, seasonal_occasion}; `caption`; `img_url`; `status` {pending_review, approved, rejected}; `regenerate_count`; `was_edited`; `created_at`; `updated_at`; `reviewed_at` nullable |
| **SeasonalOccasion** | `occasion_id` PK; `created_by_admin_id` FK → AdminProfile; `name`; `start_date`; `end_date`; `status` {active, inactive}; `created_at`; `updated_at` |
| **NotificationLog** | `notification_log_id` PK; `recipient_account_id` FK → Account; `type` {order_confirmed, order_status_update, delivery_status_update, subscription_delivery_reminder, subscription_delivery_deferred, subscription_status_update, custom_cake_status_update, subscription_renewal_reminder, email_verification_otp, password_reset_otp, account_setup}; `provider` {brevo, semaphore}; `status` {pending, sent, failed}; `error_message` nullable; `sent_at` nullable; `related_entity_type` {order, subscription, subscription_deferment, custom_cake_request, delivery, payment, account_verification}; `related_entity_id`; `created_at` |
| **SystemNotification** | `system_notification_id` PK; `recipient_role` {admin, staff, all}; `notification_type` {new_order, custom_cake_submitted, low_stock_alert, subscription_deferment_completed, payment_received, post_draft_ready, notification_send_failed}; `message`; `related_entity_type` {order, custom_cake_request, inventory, subscription, subscription_deferment, payment, post_draft, notification_log}; `related_entity_id`; `is_read` default false; `read_at` nullable; `created_at`. One user's acknowledgement is sufficient to mark the notification read. |
| **CustomerFeedback** | `feedback_id` PK; `order_item_id` FK, UNIQUE → OrderItem; `customer_id` FK → CustomerProfile; `hidden_by_admin_id` FK nullable → AdminProfile; `rating` {1–5}; `comment` nullable; `status` {visible, hidden}; `hidden_reason` {spam, abusive_language, off_topic, sexual_content, other} nullable; `hidden_at` nullable; `created_at`; `updated_at` |
| **FeedbackImage** | `feedback_image_id` PK; `feedback_id` FK → CustomerFeedback; `img_url`; `created_at`. Maximum two images per feedback. |
